# Lists in Python

## What is a List?

A list is an ordered, mutable collection that allows duplicate values.

Example:

```python
numbers = [10, 20, 30]
```

---

## Features

- Ordered
- Mutable
- Allows duplicates
- Supports multiple data types

---

## Common Methods

- append()
- extend()
- insert()
- remove()
- pop()
- clear()
- copy()
- sort()
- reverse()
- index()
- count()

---

## Best Practices

- Use lists for collections that change.
- Prefer list comprehensions for simple transformations.
