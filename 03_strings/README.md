# Strings in Python

## What is a String?

A string is a sequence of characters enclosed in single, double or triple quotes.

Example:

```python
name = "Vinoth"
```

---

## String Operations

- Indexing
- Slicing
- Concatenation
- Repetition
- Membership

---

- upper()
- lower()
- title()
- capitalize()
- strip()
- replace()
- split()
- join()
- find()
- count()
- startswith()
- endswith()

---

## Best Practices

- Use f-strings for formatting.
- Strip user input.
- Prefer string methods over manual loops where possible.
