# Exception Handling in Python

## What is an Exception?

An exception is an error that occurs during program execution.

---

## Keywords

- try
- except
- else
- finally
- raise

---

## Common Exceptions

- ZeroDivisionError
- ValueError
- TypeError
- FileNotFoundError
- IndexError
- KeyError

---

## Best Practices

- Catch specific exceptions.
- Avoid using bare except.
- Use finally to release resources.
