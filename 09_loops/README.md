# Loops in Python

## What is a Loop?

A loop repeatedly executes a block of code.

---

## Types of Loops

- for loop
- while loop

---

## Loop Control Statements

- break
- continue
- pass

---

## Common Functions

- range()
- enumerate()
- zip()

---

## Best Practices

- Use for loops when the number of iterations is known.
- Use while loops for condition-based iteration.
- Avoid infinite loops.
