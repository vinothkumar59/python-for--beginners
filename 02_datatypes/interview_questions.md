# Data Types Interview Answers

## 1. What is a data type?

A data type specifies what kind of value a variable stores.

---

## 2. Name all built-in data types.

- int
- float
- complex
- bool
- str
- list
- tuple
- dict
- set
- NoneType

---

## 3. Difference between int and float?

int stores whole numbers.

float stores decimal numbers.

---

## 4. What is a complex number?

A number containing a real and imaginary part.

Example:

```python
3 + 5j
```

---

## 5. Difference between list and tuple?

List is mutable.

Tuple is immutable.

---

## 6. Difference between dictionary and set?

Dictionary stores key-value pairs.

Set stores unique values.

---

## 7. What is None?

Represents the absence of a value.

---

## 8. Difference between type() and isinstance()?

type() returns the exact type.

isinstance() checks whether an object belongs to a class.

---

## 9. What is type conversion?

Changing one data type into another.

Example:

```python
int("100")
float(25)
str(100)
```

---

## 10. Mutable objects?

- list
- dict
- set

---

## 11. Immutable objects?

- int
- float
- bool
- tuple
- str

---

## 12. What does id() return?

Returns the unique identity (memory reference) of an object.

---

## 13. What is bool?

Stores either True or False.

---

## 14. What are sequence data types?

- str
- list
- tuple

---

## 15. Which data type is mostly used in Data Engineering?

- list
- dictionary
- string
- tuple
