# Data Types in Python

## What is a Data Type?

A data type defines the type of value a variable can store.

Example:

```python
age = 28
name = "Vinoth"
salary = 45000.75
```

---

## Built-in Data Types

### Numeric

- int
- float
- complex

### Boolean

- bool

### Sequence

- str
- list
- tuple

### Mapping

- dict

### Set

- set

### None

- NoneType

---

## Type Checking

```python
print(type(100))
```

---

## isinstance()

```python
print(isinstance(100, int))
```

---

## Type Conversion

```python
int()
float()
str()
list()
tuple()
set()
dict()
bool()
```

---

## Best Practices

- Use the correct data type.
- Avoid unnecessary conversions.
- Use isinstance() when checking object types.
