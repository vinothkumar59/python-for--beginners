# Variables in Python

## What is a Variable?

A variable is a name used to store data in memory.

Example:

```python
name = "Vinoth"
age = 28
salary = 45000.75
```

---

## Rules

- Variable names must start with a letter or underscore (_)
- Variable names cannot start with a number
- Variable names are case-sensitive
- Avoid Python keywords

Valid:

```python
employee_name = "Rahul"
_age = 25
salary = 50000
```

Invalid:

```python
2name = "Rahul"
employee-name = "Rahul"
class = "Python"
```

---

- int

type()

## Best Practices

- Use meaningful variable names.
- Follow snake_case naming.
- Avoid single-letter names except in loops.

Example:

```python
employee_salary = 55000
```
