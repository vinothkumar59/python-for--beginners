# Tuples in Python

## What is a Tuple?

A tuple is an ordered, immutable collection that allows duplicate values.

Example:

```python
numbers = (10, 20, 30)
```

---

## Features

- Ordered
- Immutable
- Allows duplicates
- Faster than lists
- Supports multiple data types

---

## Common Functions

- len()
- count()
- index()

---

## Best Practices

- Use tuples for fixed data.
- Tuples are safer because they cannot be modified.
