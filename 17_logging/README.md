# Logging in Python

## What is Logging?

Logging is used to record events, errors, warnings, and program execution details.

---

## Logging Levels

- DEBUG
- INFO
- WARNING
- ERROR
- CRITICAL

---

## Common Functions

- logging.debug()
- logging.info()
- logging.warning()
- logging.error()
- logging.critical()

---

## Best Practices

- Use logging instead of print() in production.
- Store logs in a log file.
- Use appropriate log levels.
