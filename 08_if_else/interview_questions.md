# If Else Interview Questions (Questions with Answers)

## 1. What is an if statement?

**Answer:** It executes a block of code when a condition is True.

---

## 2. Difference between if and if else?

**Answer:**

- if executes only when the condition is True.
- if else executes one of two blocks.

---

## 3. What is elif?

**Answer:** Used to check multiple conditions.

---

## 4. What is a nested if?

**Answer:** An if statement inside another if statement.

---

## 5. What are comparison operators?

**Answer:**

- ==
- !=
- >
- <
- >=
- <=

---

## 6. What are logical operators?

**Answer:**

- and
- or
- not

---

## 7. What is a ternary operator?

**Answer:**

```python
result = "Adult" if age >= 18 else "Minor"
```

---

## 8. Difference between == and =?

**Answer:**

- `=` assigns a value.
- `==` compares two values.

---

## 9. Where is if-else used in Data Engineering?

**Answer:** Data validation, filtering records, ETL transformations, null checks, business rules, and routing logic.

---

## 10. Which conditional statements are most common in Python?

**Answer:**

- if
- if else
- if elif else
- nested if
- ternary operator
