# JSON in Python

## What is JSON?

JSON (JavaScript Object Notation) is a lightweight data-interchange format.

Example:

```json
{
    "id":101,
    "name":"Vinoth",
    "salary":60000
}
```

---

## json Module

- json.load()
- json.loads()
- json.dump()
- json.dumps()

---

## Best Practices

- Use JSON for APIs and configuration files.
- Always validate JSON before processing.
