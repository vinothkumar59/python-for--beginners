# Generators in Python

## What is a Generator?

A generator is a special type of function that returns values one at a time using the `yield` keyword.

Unlike a normal function, a generator does not return all values at once.

---

## Keywords

- yield
- next()

---

## Benefits

- Memory efficient
- Faster for large datasets
- Lazy evaluation

---

## Best Practices

- Use generators for processing large files.
- Use generators instead of lists when data is produced one item at a time.
