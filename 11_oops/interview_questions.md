# OOP Interview Questions (Questions with Answers)

## 1. What is OOP?

**Answer:** OOP is a programming paradigm that uses classes and objects to organize code.

---

## 2. What is a class?

**Answer:** A class is a blueprint for creating objects.

---

## 3. What is an object?

**Answer:** An object is an instance of a class.

---

## 4. What is a constructor?

**Answer:** The `__init__()` method initializes object attributes when an object is created.

---

## 5. What is inheritance?

**Answer:** Inheritance allows one class to reuse the properties and methods of another class.

---

## 6. What is method overriding?

**Answer:** Providing a new implementation of a parent class method in the child class.

---

## 7. What is encapsulation?

**Answer:** Encapsulation restricts direct access to data by using private attributes and methods.

---

## 8. What is polymorphism?

**Answer:** Polymorphism allows the same method name to have different implementations in different classes.

---

## 9. Difference between class method and static method?

**Answer:**

- `@classmethod` works with the class (`cls`).
- `@staticmethod` does not access class or instance data.

---

## 10. Why is OOP used in Data Engineering?

**Answer:** OOP helps organize ETL pipelines, data models, database connections, API clients, and reusable business logic into maintainable, reusable classes.
