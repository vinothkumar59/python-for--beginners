# Patterns Interview Questions (Questions with Answers)

## 1. Why are pattern programs asked in interviews?

**Answer:** Pattern programs test your understanding of loops, nested loops, conditions, and logic building.

---

## 2. Which Python concepts are mainly used in pattern programs?

**Answer:**

- for loop
- while loop
- nested loops
- range()
- if statements

---

## 3. What is a nested loop?

**Answer:** A loop inside another loop. The outer loop controls rows, and the inner loop controls columns.

---

## 4. How do you print a square star pattern?

**Answer:**

```python
for i in range(5):
    print("* " * 5)
```

---

## 5. How do you print a left triangle?

**Answer:**

```python
for i in range(1, 6):
    print("* " * i)
```

---

## 6. How do you print an inverted triangle?

**Answer:**

```python
for i in range(5, 0, -1):
    print("* " * i)
```

---

## 7. What is Floyd's Triangle?

**Answer:** A triangular pattern of consecutive numbers where each row contains one more number than the previous row.

---

## 8. Are pattern programs used in Data Engineering?

**Answer:** No. Pattern programs are mainly used in coding interviews to evaluate logical thinking. They are rarely used in production Data Engineering work.

---

## 9. What is the most important skill learned from pattern programs?

**Answer:** Understanding nested loops and controlling rows and columns.

---

## 10. Which topics should you master before solving patterns?

**Answer:**

- for loop
- range()
- nested loops
- if statements
- print() with `end`
