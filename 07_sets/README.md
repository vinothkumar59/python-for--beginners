# Sets in Python

## What is a Set?

A set is an unordered, mutable collection of unique elements.

Example:

```python
numbers = {10, 20, 30}
```

---

## Features

- Unordered
- Mutable
- Unique values only
- No duplicate values

---

## Common Methods

- add()
- update()
- remove()
- discard()
- pop()
- clear()
- copy()
- union()
- intersection()
- difference()
- symmetric_difference()

---

## Best Practices

- Use sets to remove duplicates.
- Use set operations for comparisons.
