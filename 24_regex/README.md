# Regular Expressions (Regex) in Python

## What is Regex?

Regular Expressions (Regex) are patterns used to search, validate, extract, and replace text.

---

## re Module

- search()
- match()
- findall()
- finditer()
- sub()
- split()

---

## Common Patterns

- \d  → Digit
- \D  → Non-digit
- \w  → Word character
- \W  → Non-word character
- \s  → Whitespace
- .   → Any character
- ^   → Starts with
- $   → Ends with

---

## Best Practices

- Use raw strings (r"pattern").
- Keep regex patterns simple and readable.
