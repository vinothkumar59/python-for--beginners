# Functions Interview Questions (Questions with Answers)

## 1. What is a function?

**Answer:** A function is a reusable block of code used to perform a specific task.

---

## 2. Difference between parameter and argument?

**Answer:**

- Parameter → Variable in function definition.
- Argument → Value passed during function call.

---

## 3. What is the return statement?

**Answer:** It sends a value back to the caller and terminates the function.

---

## 4. Difference between print() and return?

**Answer:**

- print() displays output.
- return sends the value back for further use.

---

## 5. What are default arguments?

**Answer:** Parameters with predefined values.

Example:

```python
def country(name="India"):
    print(name)
```

---

## 6. What are keyword arguments?

**Answer:** Arguments passed using parameter names.

Example:

```python
student(age=28, name="Vinoth")
```

---

## 7. What is *args?

**Answer:** It allows a function to accept any number of positional arguments.

---

## 8. What is **kwargs?

**Answer:** It allows a function to accept any number of keyword arguments.

---

## 9. What is recursion?

**Answer:** A function calling itself until a stopping condition is reached.

---

## 10. Where are functions used in Data Engineering?

**Answer:** Functions are used to build reusable ETL logic, data validation, transformations, calculations, logging, API calls, and file processing.
