# Functions in Python

## What is a Function?

A function is a reusable block of code that performs a specific task.

Example:

```python
def greet():
    print("Hello")
```

---

## Types of Functions

- Built-in Functions
- User-defined Functions
- Anonymous (Lambda) Functions
- Recursive Functions

---

## Function Components

- def
- Function Name
- Parameters
- Arguments
- return

---

## Best Practices

- Use meaningful function names.
- Keep functions small.
- Return values instead of using print whenever possible.
