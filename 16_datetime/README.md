# Datetime in Python

## What is datetime?

The `datetime` module is used to work with dates and times.

---

## Common Classes

- date
- time
- datetime
- timedelta

---

## Common Methods

- now()
- today()
- strftime()
- strptime()
- date()
- time()
- weekday()

---

## Best Practices

- Use `datetime.now()` for the current date and time.
- Use `strftime()` for formatting.
- Use `strptime()` for parsing date strings.
